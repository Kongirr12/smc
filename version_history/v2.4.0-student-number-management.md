# MHC Smart School - Version 2.4.0 Release Notes

**วันที่อัปเดต:** 23 กันยายน 2569  
**หัวข้อการปรับปรุง:** ระบบกำหนดและจัดการเลขที่นักเรียน (Student Roll Number Management) & จัดเรียงเลขที่อัตโนมัติตามมาตรฐาน สพฐ. / SGS

---

## 🎯 ปัญหาและความต้องการ (Background & Problem Statement)
1. **เลขที่นักเรียนเดิมไม่ได้ถูกบันทึกจริงในฐานข้อมูล:** ก่อนหน้านี้ ในหน้ารายชื่อนักเรียนในห้องเรียนและหน้าเช็คชื่อ ระบบใช้การแสดงลำดับตาม Index ในอาเรย์ `(เลขที่ ${i+1})` ชั่วคราว ซึ่งเมื่อมีนักเรียนย้ายเข้า ย้ายออก หรือจัดเรียงใหม่ ลำดับจะไม่ตรงกับเลขที่จริงในห้องเรียน
2. **ความต้องการของผู้ใช้งาน:**
   - อยากให้สามารถกำหนดและบันทึกเลขที่นักเรียนแต่ละคนได้จริง
   - อยากให้มีระบบจัดเรียงเลขที่อัตโนมัติตามมาตรฐานงานทะเบียนวัดผลของโรงเรียน (มาตรฐาน สพฐ. / SGS คือ นักเรียนชายเรียง ก-ฮ ก่อน แล้วตามด้วยนักเรียนหญิง ก-ฮ)
   - สามารถแก้ไขเลขที่รายบุคคลหรือพิมพ์แก้ไขเองได้โดยตรงในหน้ารายชื่อห้องเรียน
   - สามารถระบุเลขที่จากไฟล์ CSV หรือในฟอร์มเพิ่ม/แก้ไขข้อมูลนักเรียนได้ทันที
   - ระบบเช็คชื่อ (Attendance) ต้องเรียงตามเลขที่จริง และแสดงเลขที่ในตารางเช็คชื่อ

---

## 🚀 ฟีเจอร์ที่พัฒนาใหม่ในเวอร์ชัน 2.4.0

### 1. ฟิลด์ข้อมูล `student_number` (เลขที่นักเรียน)
- เพิ่มฟิลด์ `student_number` (ประเภทตัวเลขจำนวนเต็ม) ในโมเดลข้อมูลนักเรียน Sheet `Students`
- รองรับการบันทึก, อัปเดต และคัดลอกข้อมูลโดยไม่ต้อง Migrate ฐานข้อมูล เพราะโครงสร้างเป็น JSON Schema
- ปรับปรุง API `saveStudent` ให้รับและตรวจสอบ `student_number` (ต้องเป็นจำนวนเต็มบวก > 0 หรือค่าว่าง)

### 2. ระบบจัดเรียงเลขที่อัตโนมัติ (Auto-Assign Student Roll Numbers)
- เพิ่ม Backend API `autoAssignStudentNumbers(classroomName, academicYear, mode, sessionToken)`
- มีตัวเลือก 3 โหมดในการจัดเรียง:
  1. **ตามมาตรฐาน สพฐ. / SGS (แนะนำ):** เรียงนักเรียนชาย (ก-ฮ) ก่อน จากนั้นตามด้วยนักเรียนหญิง (ก-ฮ)
  2. **เรียงตามชื่อ ก-ฮ (ทั้งหมด):** เรียงชื่อนักเรียนทุกคนตามพยัญชนะไทย ก ถึง ฮ
  3. **เรียงตามเลขประจำตัวนักเรียน (SGS ID):** เรียงตามรหัสประจำตัวนักเรียนจากน้อยไปมาก
- เมื่อจัดเรียงเสร็จ ระบบจะกำหนด `student_number` เริ่มจาก 1, 2, 3, ... ให้ทุกคนในห้องนั้นและบันทึกลง Sheet ทันที

### 3. ระบบแก้ไขเลขที่นักเรียนโดยตรง (Inline Roll Number Editing)
- ใน Modal "จัดการห้องเรียน" เพิ่มปุ่ม **[แก้ไขเลขที่]** และ **[จัดเรียงเลขที่]**
- เมื่อกด **"แก้ไขเลขที่"** ระบบจะเปลี่ยนป้ายเลขที่เป็นช่อง Input ให้คุณครูกรอกหรือแก้ไขเลขที่นักเรียนแต่ละคนได้ทันใจ
- เมื่อกด **"บันทึกเลขที่"** จะเรียก API `updateStudentNumbers(classroomName, academicYear, numberMap, sessionToken)` บันทึกเลขที่ทั้งหมดในครั้งเดียว

### 4. การจัดการเลขที่ในฟอร์มข้อมูลนักเรียน & ตารางข้อมูลนักเรียน
- **ฟอร์มเพิ่ม/แก้ไขนักเรียน (`showStudentForm`):** เพิ่มช่อง "เลขที่" ในหมวดข้อมูลการศึกษา จัดวางคู่กับเลขประจำตัว SGS, ชั้น และปีการศึกษา
- **ตารางข้อมูลนักเรียน (`renderStudentsTable`):** แสดงป้าย `เลขที่ X` สีฟ้าเด่นชัดหน้าชื่อนักเรียน
- **หน้าดูรายละเอียดนักเรียน (`viewStudent`):** แสดงรหัสและเลขที่นักเรียน

### 5. การนำเข้าเลขที่จากไฟล์ CSV (`importStudentsCSV`)
- รองรับคอลัมน์เลขที่จากไฟล์ CSV โดยตรวจจับหัวตารางชื่อ: `เลขที่`, `ลำดับที่`, `ลำดับ`, `student_number`, `seat_number`, `no`
- แสดงเลขที่ในตาราง Preview ก่อนกดยืนยันการนำเข้า
- นำเข้าและอัปเดตเลขที่เข้าฐานข้อมูลโดยอัตโนมัติ

### 6. ระบบเช็คชื่อเข้าเรียน (Attendance)
- ฟังก์ชัน `getAttendanceByClassDate` และ `getAttendanceBySubjectDate` จะจัดเรียงนักเรียนตาม `student_number` (ตัวเลข) เสมอ (หากยังไม่มีเลขที่จะตกไปจัดเรียงชาย-หญิง ก-ฮ)
- คอลัมน์แรกในตารางเช็คชื่อแสดง **"เลขที่"** จริงของนักเรียน
- รองรับทั้งการแสดงผลบนคอมพิวเตอร์และมือถือ (Mobile View)

### 7. การแก้ไขเลขประจำตัวนักเรียน & ระบบสร้างรหัสอัตโนมัติ (Student ID Quick Edit & Fallback)
- **สร้างรหัสอัตโนมัติเมื่อเว้นว่าง:** หากเพิ่มนักเรียนใหม่ หรือนำเข้าไฟล์ CSV ที่ไม่มีคอลัมน์เลขประจำตัว ระบบจะสร้างรหัสรันนิ่ง (`25680001`...) ให้อัตโนมัติเหมือนเดิม ไม่ปล่อยให้ว่าง
- **ใช้รหัส SGS เมื่อมีข้อมูล:** หากไฟล์ CSV หรือฟอร์มมีการระบุเลขประจำตัว SGS ระบบจะใช้รหัสนั้นโดยตรง
- **แก้ไขเลขประจำตัวนักเรียนได้ทุกเมื่อ:**
  - **แก้ไขด่วน (Quick Edit):** สามารถคลิกที่เลขประจำตัวนักเรียนในตารางข้อมูลนักเรียน จะมีหน้าต่างขึ้นมาให้พิมพ์แก้ไขรหัส SGS หรือเปลี่ยนเลขประจำตัวได้ทันใจ
  - **แก้ไขในฟอร์ม:** ในหน้าต่างแก้ไขข้อมูลนักเรียน สามารถดูและแก้ไขเลขประจำตัวนักเรียนได้ตามปกติ

## 📋 วิธีการทดสอบและใช้งาน
1. **จัดเรียงเลขที่อัตโนมัติในห้องเรียน:**
   - ไปที่เมนู **"ห้องเรียน"** -> กดปุ่มสีน้ำเงิน **"นักเรียน"** ของห้องที่ต้องการ
   - กดปุ่ม **"จัดเรียงเลขที่"** ที่แถบด้านบน -> เลือก **"ตามมาตรฐาน สพฐ. / SGS"** -> กด **"จัดเรียงทันที"**
2. **แก้ไขเลขที่ด้วยตนเอง:**
   - ในหน้าต่างนักเรียนของห้องเรียน กดปุ่ม **"แก้ไขเลขที่"** -> พิมพ์เปลี่ยนตัวเลข -> กด **"บันทึกเลขที่"**
3. **แก้ไขเลขประจำตัวนักเรียนแบบด่วน:**
   - ในเมนู **"ข้อมูลนักเรียน"** คลิกที่เลขประจำตัวของนักเรียนคนใดก็ได้ในตาราง
   - พิมพ์รหัสประจำตัว SGS ใหม่ที่ต้องการ -> กด **"บันทึก"**
4. **กำหนดเลขประจำตัวและเลขที่ในฟอร์ม:**
   - กดไอคอน **แก้ไข (ดินสอ)** ของนักเรียน -> ปรับแก้ช่อง "เลขที่" หรือ "เลขประจำตัวนักเรียน" -> กดบันทึก
