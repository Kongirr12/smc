# MHC Smart School - Version 2.5.1 Release Notes

**วันที่อัปเดต:** 23 กันยายน 2569  
**หัวข้อการปรับปรุง:** ปลดล็อกให้บัญชีครู (Teacher) สามารถเช็คชื่อแถวหน้าเสาธง / โฮมรูม ได้เช่นเดียวกับแอดมิน (Unlock Homeroom & Flag Assembly Attendance for Teachers)

---

## 🎯 ปัญหาที่พบ (User Issue)
ผู้ใช้งานสอบถามว่า:
> *"ทำไมไอดีของครูไม่มีการเช็คชื่อหน้าเสาธงเหมือนของ admin ครับ"*

พร้อมแนบภาพเปรียบเทียบระหว่าง:
- **บัญชีครู (`role: 'teacher'`):** หน้าการเข้าเรียนแสดงเพียงข้อความ `[ บันทึกรายวิชา ]` โดยไม่มีปุ่มสลับไปโหมดหน้าเสาธง
- **บัญชีแอดมิน (`role: 'admin'`):** มีปุ่มสลับแท็บ `[ รายวิชา ]` และ `[ หน้าเสาธง / โฮมรูม ]`

### สาเหตุที่แท้จริง (Root Cause)
ในโค้ดเดิมของ [`js2.js`](file:///Users/macos/Desktop/anti/smart%20sch/js2.js) บรรทัดที่ 1850 มีเงื่อนไขดักไว้ว่า:
```javascript
${APP.role !== 'teacher' ? `
<div class="flex rounded-lg overflow-hidden border border-slate-200">
  <button id="attModeSubject"> ... รายวิชา ... </button>
  <button id="attModeClass"> ... หน้าเสาธง / โฮมรูม ... </button>
</div>
` : '<span class="text-sm font-semibold text-blue-600">บันทึกรายวิชา</span>'}
```
และบรรทัดที่ 1799 กำหนดให้ครูถูกบังคับเข้าสู่โหมด `subject` ตลอดเวลา ทำให้ปุ่ม `[ หน้าเสาธง / โฮมรูม ]` ถูกซ่อนไปสำหรับบัญชีครู

---

## 🚀 การแก้ไขและปรับปรุง (Solution)

1. **เปิดให้ทุกบทบาท (ครู, เจ้าหน้าที่, แอดมิน) เข้าถึงทั้ง 2 โหมด:**
   - ปรับแก้ใน [`js2.js`](file:///Users/macos/Desktop/anti/smart%20sch/js2.js) ให้แสดงปุ่มสลับโหมด `[ รายวิชา ]` และ `[ หน้าเสาธง / โฮมรูม ]` ให้ครูทุกคนใช้งานได้อิสระ
2. **ตั้งค่าโหมดเริ่มต้น:**
   - หากยังไม่ได้เลือก ให้เริ่มต้นที่ `หน้าเสาธง / โฮมรูม` (Class Mode) ซึ่งเป็นกิจกรรมแรกของวัน หรือจดจำโหมดล่าสุดที่ครูเลือกไว้
3. **การทำงานร่วมกับระบบฐานข้อมูล:**
   - ฟังก์ชัน Backend `getAttendanceByClassDate` และ `saveAttendanceBulk` ใน [`code.gs`](file:///Users/macos/Desktop/anti/smart%20sch/code.gs) รองรับการบันทึกหน้าเสาธงของครูอยู่แล้ว ไม่ต้องแก้ไขเพิ่มเติม
