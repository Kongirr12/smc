## 🎯 ปัญหาเดิมที่พบ (Issues & Motivation)
1. **ปัญหา Session Invalid / Session หมดอายุ:**
   - เมื่อผู้ใช้ปล่อยหน้าจอทิ้งไว้นานจน Token หมดอายุ หรือ Session ในชีต `Sessions` ถูกลบ ระบบจะขึ้น Error ว่า `session_invalid` หรือหมุนค้าง แต่ไม่ยอมนำผู้ใช้ออกไปยังหน้าล็อกอินใหม่ ทำให้เกิดความสับสน
2. **การจัดการห้องเรียนนักเรียนทีละคนช้าเกินไป:**
   - ในช่วงเปิดเทอมหรือเลื่อนชั้นเรียน ครูต้องเข้าไปกดแก้ไขข้อมูลนักเรียนทีละคนเพื่อเปลี่ยนห้องเรียน ทำให้เสียเวลาอย่างมาก หากมีนักเรียน 500-1000 คน

## 🛠️ รายละเอียดการแก้ไขและฟีเจอร์ใหม่ (Key Changes)

### 1. ระบบดักจับ Session Invalid และ Auto-logout (Session Guard)
- เพิ่มตัวดักจับใน Global API Runner (`index.html`) และ `js1.js`:
  - หาก API ส่งสถานะ `session_invalid`, `session_expired` หรือข้อความเกี่ยวกับสิทธิ์ไม่ถูกต้อง
  - แสดงแจ้งเตือน SweetAlert2 แจ้งผู้ใช้ว่า: *"เซสชันการเข้าสู่ระบบหมดอายุ กรุณาเข้าสู่ระบบใหม่อีกครั้ง"*
  - ล้าง `localStorage` และ Token ของผู้ใช้ทั้งหมด
  - นำทางผู้ใช้กลับไปยังหน้าล็อกอิน (`renderLogin()`) ทันทีอย่างปลอดภัย

### 2. แถบเครื่องมือเลือกนักเรียนแบบกลุ่ม (`#stBatchBar`)
- เพิ่ม Checkbox ในหัวตาราง (`#stSelectAll`) เพื่อเลือกนักเรียนทุกคนในหน้านั้น
- เพิ่ม Checkbox ประจำตัวนักเรียนแต่ละแถว (`.st-chk`)
- เพิ่มตัวเลือก **"เลือกทั้งหมด X คนตามตัวกรองนี้"** (`selectAllMatchingStudents`) ทำให้สามารถเลือกนักเรียนข้ามหน้า Pagination ได้ทั้งหมดในคลิกเดียว

### 3. ระบบย้าย/กำหนดห้องเรียนแบบกลุ่ม (Batch Assign Classroom)
- เพิ่มปุ่ม **"กำหนดชั้นเรียนให้นักเรียนที่เลือก"** ในแถบ Action Bar
- เปิด Modal ให้เลือกห้องเรียนเป้าหมาย หรือพิมพ์ชื่อห้องเรียนใหม่ได้ทันที พร้อมระบุปีการศึกษา
- ส่งคำขอไปยังฟังก์ชัน `transferStudents` ใน `code.gs` เพื่ออัปเดตข้อมูลนักเรียนทั้งหมดในคราวเดียว
