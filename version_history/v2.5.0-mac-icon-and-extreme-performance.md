# MHC Smart School - Version 2.5.0 Release Notes

**วันที่อัปเดต:** 23 กันยายน 2569  
**หัวข้อการปรับปรุง:** เปลี่ยน Favicon เป็นไอคอน Mac (แชร์ที่คั่นหน้า / Safari Touch Icon / PWA) & ปรับแต่งประสิทธิภาพทั้งระบบให้เร็วที่สุด (Extreme Performance Optimization)

---

## 🎯 ปัญหาและความต้องการ (User Requirements)
1. **ไอคอน Favicon และการแชร์ที่คั่นหน้าใน Mac:**
   - ผู้ใช้ต้องการให้ Favicon บนแท็บเบราว์เซอร์ เป็นไอคอนเดียวกันกับที่ปรากฏเวลาแชร์ที่คั่นหน้าหรือบุ๊กมาร์กใน Mac (`app-icon.jpg` / Apple Touch Icon)
   - ปัญหาเดิม: เบราว์เซอร์ถูกสั่งให้เขียนทับ `favicon.href` ด้วย `config.school_logo` (ตราโรงเรียนที่เป็นไฟล์ Google Drive) และไม่มีชุดไฟล์ Favicon ความละเอียดสูงสำหรับ Mac / iOS / Android / PWA
2. **ประสิทธิภาพการทำงานสูงสุด (Speed & Performance):**
   - ผู้ใช้ต้องการให้ระบบทำงานไวที่สุด เท่าที่จะเป็นไปได้ ("เอาแบบไวที่สุดนะครับระบบ")

## 🚀 ฟีเจอร์และการปรับปรุงในเวอร์ชัน 2.5.0

### 1. 🍎 ระบบไอคอน Mac, Safari Bookmark & PWA Web App
- แปลงไฟล์ต้นฉบับ `app-icon.jpg` เป็นชุดไอคอนมาตรฐานสากล:
  - `favicon.ico` (32x32 Windows / Browser Tab Icon)
  - `favicon-32.png` (32x32 Retina Tab Icon)
  - `favicon-192.png` (192x192 Android / Mobile Home Screen)
  - `favicon-512.png` (512x512 High-Res Splash Screen)
  - `apple-touch-icon.png` (180x180 สำหรับ macOS Safari Bookmark, Reading List, Share Sheet และ iOS Home Screen)
- สร้างไฟล์ `manifest.json` สำหรับรองรับการติดตั้งเป็น Progressive Web App (PWA) บน Mac, PC, และมือถือ
- เพิ่ม Open Graph Meta Tags (`og:image`, `og:title`, `og:description`, `twitter:image`) สำหรับการส่งต่อลิงก์ใน Messages, Line, Facebook, AirDrop บน Mac
- ป้องกันการถูกแทนที่ Favicon: ยกเลิกคำสั่งเขียนทับ Favicon จากตราโรงเรียนใน `index.html` และ `js1.js` เพื่อรักษาไอคอนแอป Mac ไว้เสมอ

---

### 2. ⚡ การปรับแต่งความเร็วฝั่ง Backend (Google Apps Script - `code.gs`)
- **ตัดภาระการอ่าน Sheet ซ้ำซ้อน 100% ใน `getDashboardData`:**
  - เปลี่ยนจากการเรียก `validateSession` ตัวใหญ่ (ที่อ่าน 7 Sheets) มาเป็น `validateSessionLight_` (อ่านเฉพาะ Token Cache ในแรม) ช่วยลดรอบการอ่านฐานข้อมูลลงกว่า 7 Sheets ต่อ Request
- **ระบบ Cache แดชบอร์ดความเร็วสูง (`dashboard_core_cache`):**
  - ในฟังก์ชัน `getDashboardDataCore_` เพิ่มระบบแคชใน `CacheService` เป็นเวลา 30 วินาที
  - หากไม่มีการแก้ไขข้อมูล แดชบอร์ดจะตอบกลับในเวลาไม่กี่มิลลิวินาที โดยไม่ต้องสแกน Google Sheets ซ้ำ
- **ระบบ Auto-Cache Invalidation:**
  - เมื่อมีการบันทึก แก้ไข หรือลบข้อมูลใน `appendJsonRow_`, `appendJsonRows_`, และ `writeJsonSheet_` ระบบจะสั่งล้าง `dashboard_core_cache` ทันที ข้อมูลใหม่จึงแสดงผลอย่างถูกต้องและแม่นยำเสมอ

---

### 3. 🏎️ การปรับแต่งความเร็วฝั่ง Frontend (`index.html` & `js1.js`)
- **Stale-While-Revalidate (SWR) & Instant 0ms Navigation:**
  - เพิ่มการแคชผลลัพธ์คำสั่งอ่านข้อมูลบ่อยๆ ลงใน `_apiCache` (เช่น `getStudents`, `getClassrooms`, `getSubjects`, `getPersonnel`, `getCalendarEvents`, `getRooms`, `getSchoolYear`, `getDashboardData`, `getSidebarBadges`)
  - เมื่อผู้ใช้สลับหน้า เช่น จากหน้าแดชบอร์ดไปหน้านักเรียน แล้วกดกลับมา ข้อมูลจะแสดงผล **ทันทีใน 0 มิลลิวินาที (Instant UI)** โดยไม่ต้องแสดงวงล้อหมุนโหลด
  - ระบบจะดึงข้อมูลสดจากเซิร์ฟเวอร์อยู่เบื้องหลังอย่างเงียบๆ และอัปเดตหน้าจอให้อัตโนมัติหากมีข้อมูลเปลี่ยนแปลง
- **Persistent Dropdown Hydration (SessionStorage):**
  - รายชื่อห้องเรียน ครู และการตั้งค่าพื้นฐาน จะถูกสำรองไว้ใน `sessionStorage` ทันทีที่โหลดครั้งแรก
  - เมื่อเปิดฟอร์มหรือรีเฟรชหน้าเว็บ Dropdown ต่างๆ จะเปิดใช้งานได้ทันทีใน 0ms
- **ตัดคำสั่งโหลดแดชบอร์ดซ้ำตอน Login / Boot:**
  - บันทึก `APP._dashboardTs = Date.now()` ใน `handleSessionCheck` และ `doLogin` ทำให้ตอนเปิดระบบครั้งแรก จะไม่ยิง API `getDashboardData` ซ้ำซ้อนกับตอนเช็ค Session
- **Smart Background Polling:**
  - ใน `refreshBadges` เพิ่มเงื่อนไข `if (document.hidden) return;` เพื่อหยุดส่ง Request ตรวจสอบการแจ้งเตือนเมื่อผู้ใช้สลับไปดูแท็บอื่นหรือย่อหน้าต่างลง ช่วยประหยัดแบตเตอรี่และเน็ตบน Mac
  - เมื่อสลับกลับมาเปิดแท็บ (Event `visibilitychange`) ระบบจะดึงข้อมูลใหม่ทันที
- **CSS Preload & Head Optimization:**
  - ใส่ `<link rel="preload" href="styles.css" as="style">` ใน `<head>` เพื่อให้เบราว์เซอร์ดาวน์โหลดสไตล์ชีทคู่ขนานไปกับการประมวลผลหน้าเว็บ
