# MHC Smart School - Version 2.5.2 Release Notes

**วันที่อัปเดต:** 23 กันยายน 2569  
**หัวข้อการปรับปรุง:** ตรวจสอบและยกระดับระบบ Dark Mode ทั้งระบบ ให้อ่านง่าย สบายตา คมชัดระดับ WCAG AA (Full Dark Mode & Readability Enhancement)

---

## 🎯 วัตถุประสงค์และการตรวจสอบ (Audit & Objectives)
ผู้ใช้งานแจ้ง:
> *"เช็คฟังก์ชันการทำงานของ darkmode และการอ่านหน้าเว็บใน darkmode ครับ"*

จากการตรวจสอบโค้ดและการเรนเดอร์ในโหมดมืด (Dark Mode) พบจุดที่ต้องปรับปรุงด้านความเข้ากันได้และการอ่านเนื้อหาดังนี้:
1. **การซิงโครไนซ์ Class ระหว่าง Dark Mode และ Tailwind:**
   - โค้ดเดิมใน `index.html` และ `js1.js` มีการ toggle เพียงคลาส `dark-mode` บน `<html>` แต่ Tailwind CSS CDN ไม่ได้กำหนด `darkMode: 'class'` และขาดคลาส `dark` ทำให้ Tailwind variants โหมดมืดไม่ทำงาน
2. **ความคมชัดของ Label ใน Form และ Modal Popups (SweetAlert2):**
   - Modal ที่สร้างขึ้นในหน้าต่าง ๆ เช่น บันทึกเหตุการณ์, จัดการห้องเรียน, ปฏิทิน, ผู้ใช้งาน ฯลฯ มีการเขียนสไตล์ภายในกำหนด `.form-label { color: #475569; }` ซึ่งเป็นสีเทาเข้ม เมื่อแสดงผลบนพื้นหลัง Modal สีดำ/เทาเข้ม (`#111318`) ทำให้ตัวอักษรกลืนไปกับพื้นหลัง อ่านยากมาก
3. **การลำดับชั้นของสีข้อความ (Text Hierarchy & Contrast):**
   - กฎ CSS เดิม `html.dark-mode [class*="text-slate-"]` กวาดทุกคลาสที่มี slate ให้กลายเป็นสี `#94A3B8` ทั้งหมด ส่งผลให้หัวข้อหลักหรือตัวเลขสำคัญที่ใช้ `text-slate-800` หรือ `text-slate-900` ถูกลดความสว่างลง กลืนไปกับข้อความรอง
4. **กล่องข้อความและป้ายกำกับสีสว่าง (Bright Badges & Pills):**
   - กล่องข้อมูล เช่น แถบวิชาที่เลือกในหน้าเช็คชื่อ (`#attSubjectDisplay`), ป้ายเลขที่นักเรียน, แถบสถานะ และกล่องแจ้งเตือนต่าง ๆ ใช้พื้นหลังสีสว่าง (`bg-blue-50`, `bg-slate-100`, `bg-emerald-50`, `bg-amber-50`, `bg-red-50`) ซึ่งเมื่ออยู่ในโหมดมืดจะกลายเป็นกล่องสีขาวสว่างจ้าแยงตา
5. **การแสดงผลกราฟสถิติ (Chart.js Dynamism):**
   - กราฟสถิติเข้าเรียน 7 วัน, กราฟการเงิน, กราฟรายงาน 30 วัน ใช้สีเส้นตาราง `#F1F5F9` และสีข้อความตัวเลขค่าเริ่มต้น เมื่อสลับเป็นโหมดมืด เส้นตารางจะกลายเป็นสีขาวสว่าง และข้อความตัวเลขไม่ปรับสีตามธีมทันที

## 🚀 การแก้ไขและยกระดับ (Enhancements Made)

### 1. ปรับปรุงการโหลดธีมและการทำงานของปุ่ม Dark Mode (`index.html` & `js1.js`)
- กำหนด `darkMode: 'class'` ใน `tailwind.config`
- ซิงค์คลาส `dark` ควบคู่กับ `dark-mode` บน `document.documentElement` ทันทีตั้งแต่ช่วง Head script เพื่อป้องกันอาการหน้าจอกะพริบสีขาวก่อนโหลดเสร็จ (FOUC)
- ปรับปรุงฟังก์ชัน `toggleDarkMode()` ให้สลับทั้ง 2 คลาส และอัปเดตไอคอนพระอาทิตย์/พระจันทร์ (`bx-sun` / `bx-moon`) พร้อมบันทึกสถานะลงใน `localStorage` ข้ามการรีโหลดหน้าเว็บ

### 2. ปรับระดับความคมชัดและลำดับตัวอักษร (Typography & Contrast)
- กำหนดให้หัวข้อและข้อความหลัก (`.text-slate-900`, `.text-slate-800`, `.text-slate-700`, `.text-gray-900` ฯลฯ) แสดงเป็นสีขาวสว่าง `#F8FAFC !important` คมชัด มองเห็นเด่นชัด
- กำหนดให้ข้อความรอง (`.text-slate-600`, `.text-slate-500`) เป็นสี `#94A3B8 !important`
- กำหนดให้ข้อความคำใบ้/หมายเหตุ (`.text-slate-400`) เป็นสี `#64748B !important`
- บังคับให้ป้ายกำกับฟอร์ม (`.form-label`, `label`, `.swal2-content label`) แสดงเป็นสี `#CBD5E1 !important` ทำให้อ่านชื่อช่องกรอกข้อมูลในทุก Modal ได้อย่างชัดเจนสบายตา

### 3. ปรับแต่งป้ายสถานะ กล่องข้อความ และปุ่มกดให้เข้ากับธีมมืด (Badges & Components)
- **กล่องข้อมูลและป้ายกำกับ:** แปลง `bg-blue-50`, `bg-emerald-50`, `bg-amber-50`, `bg-red-50`, `bg-purple-50` และ `bg-slate-100/200` ในโหมดมืด ให้เป็นพื้นหลังโปร่งแสงแบบ Dark Frosted Glass (เช่น `rgba(99,102,241,.15)`) พร้อมสีข้อความพาสเทลสว่างที่อ่านง่าย ไม่แสบตา
- **สถานะนักเรียน/บุคลากร (`.status-active`, `.status-inactive`, `.status-pending`):** ปรับให้เรืองแสงสวยงามในโหมดมืดด้วยสีเขียวอ่อน (`#6EE7B7`), สีแดงอ่อน (`#FCA5A5`) และสีเหลืองอำพัน (`#FCD34D`)
- **การเช็คชื่อเข้าเรียน (`attendance`):** ปรับแถบแสดงวิชา `#attSubjectDisplay` และปุ่มเลือกคาบเรียน `[name="att_period"]` ให้แสดงผลเป็นสีกรมท่าเข้มพร้อมขอบไฮไลต์ เมื่อกดเลือกจะเรืองแสงสีน้ำเงินสดใส
- **หน้าต่างแจ้งเตือน Modal (SweetAlert2):** ปรับแต่งหัวข้อ, เนื้อหา, ช่องกรอก และปุ่มยกเลิก (`.swal2-styled.swal2-cancel`) ให้เป็นสไตล์ดาร์กโมดาร์น มน สบายตา
- **ช่อง Dropdown Select:** กำหนดสีพื้นหลังและสีตัวอักษรของ `<option>` ให้ถูกต้อง ป้องกันปัญหาตัวอักษรดำบนพื้นดำในบางระบบปฏิบัติการ

### 4. ซิงโครไนซ์กราฟสถิติแบบไดนามิก (Chart.js Dynamic Theme Update)
- สร้างฟังก์ชัน `applyChartTheme(isDark)` ใน `js1.js` เพื่อปรับสีเส้นตาราง (`scales.grid.color`), สีสเกลตัวเลข (`scales.ticks.color`) และสีป้ายคำอธิบายกราฟ (`legend.labels.color`) ของกราฟทั้งหมดในระบบ (`APP.charts`) แบบ Real-time ทันทีที่ผู้ใช้กดปุ่มสลับธีมโดยไม่ต้องรีเฟรชหน้าเว็บ
- ปรับแต่งการสร้างกราฟใน `js1.js` (Dashboard) และ `js4.js` (Reports) ให้ตรวจเช็คธีมปัจจุบันตั้งแต่ตอนวาดกราฟครั้งแรก
